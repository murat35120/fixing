Нативный Node JS сервер  для демонстрации работы протокола Advanced

Решаемые задачи:
0) В консоли сервера выводиятся:
- локальный адрес и порт для открытия страницы
- сетевой адрес  и порт для открытия страницы, если у компьютера несколько сетей, значит выводится  несколько адресов.
- лог событий и ошибок (можно отключить командой)
1) поиск веб конвертеров Z-397 web (RS485 в Eternet). 
Используется широковещательный запрос UDP, в ответ конвертеры отправляют информацию о себе.
Если конвертер в режиме Сервер к нему можно подключиться
2) Подключение конвертеров работающих в режиме клиент и  настроенных на работу с серавером (присылают запросы)
3) Переключение скорости передачи конвертера на   230400, что равнозначно включению режима Advanced
После этого конвертер поддерживает протокол NVT, что означает маскирование FF.
4) Сервер реализует все команды протокола. 
5) Для управления сервером есть три типа каналов связи
- HTML страница, на сервере, связи по websocket. Может быть несколько открытых одновременно страниц.
- post запросы на сервер.  Каждая команда самостоятельна.
- внутренний объект, для  последующего расширения возможностей. Может быть только один пользователь. Иметет дополнительные команды позволяющие отключить/ включить работу страницы и pocn запросов.
Сервер транслирует ответ конвертера только тому каналу который запрашивает



На странице HTML 
- виден список конвертеров, при клике по конвертеру, раскрывается список доступных контроллеров.
- каждой команде протокола соответствует своя кнопка и при необходимости поля для воода данных.
- В окне лог событий выводится название команды, отправленные байты конвертеру, полученные байты от конвертера и расшифрованная информация для чтения человеком.

Дополнительные команды сверх протокола:
- Получить список всех известных конвертеров 
- Получить список подключенных конвертеров 
- Получить список известных контроллеров
- Получить список найденых контроллеров подключенных к конвертеру
- Заблокировать конвертер = не подключаться к нему
- Удалить информацию о конвертере
- Удалить информацию о всех конвертерах
- Удалить информацию о всех контроллерах
- отключить / включить вывод лога в консоль сервера

server_udp.on('message', function (message, rinfo) {
	let msg={};
	msg.from=rinfo.address;
	let str=String(message);
	arr=str.split(' ');
	for(let i in arr){
		let k=arr[i].split(':');
		if(k.length>1){
			msg[k[0]]=k[1];
		}else{
			let ind=k[0].indexOf('SN');
			if(k[0].includes('SN')){
				msg.number=k[0].slice(ind+2); 
			}
		}
	}
	if((msg.L1_Port==port_client)||(msg.L2_Port==port_client)){
		//console.log(msg);
		if((msg.L1_Conn=='0.0.0.0')&&(msg.L2_Conn=='0.0.0.0')){
			//console.log(msg);
			new_client(msg.from);
		}
	}
});

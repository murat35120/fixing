Нативный Node JS.  
Класс для создания экземпляров объекта, решающих задачу работы с каналом связи.
Каналов связи может быть несколько, по этому нужен класс. Для каждого канала свой экземпляр объекта.
Канал связи работает по принципу Запрос-Ответ. Если ответ не получен в течении заданного времени,  считается, что ответ не получен.
Задача объекта организовать очередь выполнения команд.
Очередь состоит из двух списков основного и оперативного. Списки это Set().
Сначала выполняются команды оперативного списка, потом команда основного списка,  если оперативный список пуст выполняется следующая команда основного списка.
Когда оба списка пусты в канал ни чего не отправляется.
Для добавления команд в очередь объект имеет метод add. При его вызове указывается в какой из списков нужно добавить команду.
Добавлять команды в очередь можно в любой момент. 
Если  очередь пуста, то как только в очередь добавляется  команда, очередь, начинает обрабатываться.
Необходимо предусмотреть настройку паузу после получения ответа до отправки следующего запроса.
В класс передается указатель на функцию отправки сообщений.
В объект, метод add передаются:
- тип списка (основной или оперативный)
- ссылка на экземпляр команды (функция генератор =  function *)
- время ожидания ответа, после которого считается, что ответа нет
В объект, метод listener передаются ответное сообщение

Необходимо будет создать:
-  класс
-  сервер для демонстрации (тестирования) работы класса
